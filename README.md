## ✨ Overview

**FreeToolsHub** ([`freetools-online.github.io`](https://freetools-online.github.io/)) is a centralized directory and discovery platform showcasing an extensive suite of **60+ free, high-performance web applications**. Built with **Astro (SSG Mode)** and **Tailwind CSS**, FreeToolsHub is engineered to achieve a perfect **100/100 Lighthouse score** across Performance, Accessibility, Best Practices, and SEO.

By leveraging Astro's zero-JavaScript default architecture combined with ultra-lightweight client-side vanilla JavaScript filtering, users can instantly search, browse, and launch dedicated browser tools across 6 distinct categories without sluggish page loads or intrusive tracking.

---

## 🚀 Key Features

- **⚡ Instant Real-Time Search & Category Filtering:** Search 60+ tools simultaneously by title, description, or keyword, or filter with single-click interactive category pills with dynamic live tool counts.
- **🔒 Privacy-Focused Suite:** The majority of featured tools operate 100% client-side in the browser via WebAssembly (Wasm) and HTML5 Web APIs. Sensitive PDF contracts, images, audio clips, and files never leave the user's device.
- **🎯 100/100 Enterprise Technical SEO:**
  - Dynamic XML sitemap generation via `@astrojs/sitemap`.
  - Absolute, self-referencing canonical URLs.
  - Linked JSON-LD structured data schemas: `WebSite`, `ItemList` (featuring all 62 tools as `SoftwareApplication` entities with `$0.00` pricing), and `FAQPage` for Google rich snippets.
  - Comprehensive Open Graph and Twitter Card preview tags.
- **📱 Responsive Minimalist Layout:** Clean, distraction-free Light Theme with a fluid CSS grid (1 column on mobile, 2 on tablet, 3–4 on desktop) and smooth micro-interactions.
- **♿ WCAG 2.1 AA Accessibility Compliant:** Semantic HTML5 landmarks (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`), keyboard navigation, and explicit `aria-label` / `aria-selected` attributes.

## 🚀 Local Development

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18.14.1 or higher) and `npm` installed.

### 1. Clone the Repository

```bash
git clone https://github.com/freetools-online/freetools-online.github.io.git
cd freetools-online.github.io
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser to inspect the application.

### 4. Build for Production

```bash
npm run build
```

The fully optimized, static production output will be generated inside the `dist/` directory.

### 5. Preview Production Build

```bash
npm run preview
```

## 🚢 Deployment

FreeToolsHub is automatically built and deployed via **GitHub Actions** upon every push to the `main` branch.

1. Go to your repository settings on GitHub (`Settings` > `Pages`).
2. Set **Source** to **GitHub Actions**.
3. Pushes to `main` will trigger `.github/workflows/deploy.yml` which builds the Astro static output and deploys it live to GitHub Pages.
